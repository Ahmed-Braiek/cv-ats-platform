# Flutter Android application

Planned: Flutter stable, Riverpod state management, GoRouter navigation, immutable API models generated from OpenAPI, repository layer, theme tokens from the existing Figma export, widget and integration tests.

First screens: landing, CV/job input, processing, auth gate, register/login, results overview, ATS detail, match detail, recommendations, dashboard, history and subscription.

No secrets in Dart. Supabase publishable key can be configured for approved client auth only; privileged keys and Gemini requests stay server-side.
